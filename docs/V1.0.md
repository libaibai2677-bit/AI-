# Unified Chat V1.0

> Product contract. Do not introduce dashboard/CRM/campaign concepts into V1.

## 1. Product definition

**Unified Chat** is a local-first desktop chat workspace. Users manage chat Profiles, not browsers.

Core promise:

- No Unified Chat account
- Local first
- Multiple isolated Profiles
- WhatsApp + Telegram
- One unified inbox
- One global search
- DeepL first + Google fallback
- Local translation cache
- Intelligent message batching
- Personal Translation Style
- Profile-scoped Translation Memory
- Conversation Profile overrides
- Optional AI through a single ✨ entry point

## 2. Four-layer architecture

```text
                    Unified Chat
                         │
        ┌────────────────┼────────────────┐
        ↓                ↓                ↓
   Profile Layer    Message Layer    Intelligence Layer
        │                │                │
   多账号隔离        统一聊天          翻译 / AI
        │                │                │
        └────────────────┼────────────────┘
                         ↓
                  Local Data Layer
```

### Profile Layer

Owns profile identity, provider, isolated session/storage environment, window state, network settings, translation settings and AI settings.

### Message Layer

Normalizes provider messages into a platform-neutral conversation/message model. Unified Inbox and global search depend only on this layer.

### Intelligence Layer

Owns Translation Router, cache, batching, Translation Style, Translation Memory, Conversation Profile resolution and optional AI actions.

### Local Data Layer

Owns local persistence, encrypted vault metadata, backup manifests and search index. Provider credentials/session material are never included in a normal configuration backup.

## 3. Profile contract

The UI exposes:

- `WhatsApp · Personal`
- `WhatsApp · Work`
- `WhatsApp · Business`
- `Telegram · Personal`

The implementation may use isolated Chromium/Electron storage partitions. This implementation detail must remain invisible to the user.

Profile status values:

- Connected
- Attention
- Disconnected
- Not configured

Quick switch:

- `Ctrl/Cmd + 1..9`

Quick lock:

- `Ctrl/Cmd + Shift + L`

## 4. Settings precedence

```text
Global Settings
      ↓
Profile Settings
      ↓
Conversation Settings
```

The most specific configured value wins.

## 5. Translation pipeline

```text
Incoming message(s)
        ↓
Batch window
        ↓
Normalize + dictionary lookup
        ↓
Translation cache lookup
        ↓ miss
Translation Router
   ├── DeepL
   └── Google fallback
        ↓
Apply display mode
        ↓
Render bilingual/original/translated message
```

Cache keys must include source text, source language, target language, provider configuration/version and effective translation style/dictionary revision so stale translations are not reused incorrectly.

## 6. Backup contract

Normal `*.profile` backup contains:

- Profile metadata
- Translation settings
- UI settings
- Local configuration
- Dictionary / Translation Memory
- Backup manifest/version

It does **not** contain sensitive login credentials by default.

Encrypted backup may be offered later as an explicit user action.

## 7. V1 screens

### Chats

The default screen. Chat first, no dashboard.

### Profiles

Create/select Profiles, inspect health, open a Profile, and access backup controls.

### Search

One global search surface across Profiles and providers.

### Settings

Global translation, security, display and AI defaults.

## 8. Non-goals

V1 does not include:

- CRM
- Campaigns
- Automation sequences
- Analytics dashboards
- Browser fingerprint controls
- Security-evasion mechanisms
- A mandatory Unified Chat cloud account

## 9. Acceptance criteria

1. Launch opens directly into Chats.
2. A Profile can be selected without exposing browser terminology.
3. Profiles remain logically isolated.
4. `Ctrl/Cmd + 1..9` switches Profiles.
5. `Ctrl/Cmd + Shift + L` locks the UI.
6. Unified Inbox can represent conversations from multiple providers.
7. Global search is provider/profile agnostic.
8. Translation uses DeepL first and can fail over to Google.
9. Translation cache prevents duplicate provider calls for equivalent requests.
10. Consecutive messages can be batched before translation.
11. Translation Style and Translation Memory are scoped correctly.
12. Conversation settings override Profile and Global settings.
13. AI remains behind the ✨ action menu.
14. Normal backups exclude sensitive session credentials.
