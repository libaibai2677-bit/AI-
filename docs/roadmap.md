# V1 Roadmap

## Phase 0 — Foundation

- Repository conventions
- Desktop application shell
- Type-safe package boundaries
- Local configuration schema
- Secure storage abstraction

## Phase 1 — Profile Core

- Profile Manager
- Create / rename / delete
- Isolated storage directory/context
- Profile status model
- Quick switch
- Ctrl+1..9 shortcuts
- Quick Lock: Ctrl+Shift+L
- Profile Vault
- Trusted Device option
- Backup/export of non-sensitive configuration
- Clone configuration without credentials

## Phase 2 — Chat Core

- Provider-neutral message model
- Conversation model
- Chat-first UI
- Unified Inbox
- All / Unread / Mentions / Favorites / Follow Up
- Global cross-profile search

## Phase 3 — Provider Connections

- WhatsApp connection adapter
- Telegram connection adapter
- Session restore
- Provider status reporting
- Last-conversation restore

## Phase 4 — Translation

- Translation provider interface
- DeepL adapter
- Google adapter
- Automatic fallback router
- Local translation cache
- Short-message filtering
- Consecutive-message batching
- Personal Translation Style
- Translation Memory
- Profile-level dictionary
- Conversation-level translation preferences

## Phase 5 — Optional AI

- Hidden `✨` assistant action
- Reply
- Rewrite
- Explain
- Summarize
- Translate

## Phase 6 — Polish

- Focus Mode
- Responsive window layouts
- Accessibility
- Error recovery / Profile Health
- Import/export validation
- Crash-safe local persistence

## Explicit non-goals

The V1 product is not a CRM, campaign manager, bulk messaging tool, or anti-detection browser. Profile isolation exists for legitimate account separation, privacy, and reliability.
